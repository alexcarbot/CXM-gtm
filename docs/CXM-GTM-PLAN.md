## Product Definition

**CarBot Cloud CXM** (Customer Experience Manager) is a free, AI-native platform that sits on top of existing CRM/DMS/service schedulers to unify all dealer communications and CarBot services in one place.

### Key Capabilities (confirmed in transcripts)

| Capability | Description |
|-----------|-------------|
| Unified Conversation Hub | Every call, text, email, and AI conversation in one timeline per customer |
| Real-Time Call Streaming | Live transcription via websocket media stream as calls happen |
| AI Voice Agents | Configurable personas (voice, personality, rules) assignable to workflow steps |
| Visual Workflow Editor | Drag-and-drop process builder with AI and human steps |
| AI Watcher | Auto-schedules appointments, completes tasks, updates CRM after calls |
| Generational UI System | ~20 interface themes (Outlook, Discord, TikTok, Apple, social feed, etc.) |
| CRM Integration | VIN Solutions, eLead, DriveCentric — calls logged as calls |
| Instant Lead Verification | Outbound AI call within 5 seconds of lead submission |
| CarBot Coach | AI role-play training — 70-80% monthly active user adoption |
| Call Tracking & QA | AI-powered scoring, grading, and live monitoring |
| PII Redaction | Context-aware — redacts credit cards, preserves employer addresses |
| Compliance Stack | 10DLC, CNAM, STIR/SHAKEN, TNS branded verification |
| Multi-Device | Web, iOS native, Apple TV deployment |
| SSO Support | Enterprise authentication |

### Pricing Model

Free for any dealer using any CarBot product. Paid value-add for custom CRM integrations, AI persona development, and enterprise deployment support. Open-source release planned (not yet publicly announced).

## Dual-Audience Strategy

The CXM must speak to two fundamentally different user types simultaneously.

### Audience A: Older / Traditional Buyers

| Attribute | Detail |
|-----------|--------|
| **Who** | GMs, Operating Partners, seasoned dealership staff |
| **Mindset** | Cautious about AI, want familiarity, value reliability |
| **UI Preference** | Outlook, Apple Mail, Gmail — inbox-familiar layouts |
| **Key Concern** | *"I don't want to throw AI right into the mix"* |
| **Messaging Posture** | "Everything you already know, now all in one place" |
| **Lead With** | Consolidation, visibility, simplicity, risk reduction |
| **Avoid** | AI-forward language, technical jargon, disruption framing |

### Audience B: Younger / Tech-Savvy Users

| Attribute | Detail |
|-----------|--------|
| **Who** | BDC agents, newer salespeople, digital-native managers |
| **Mindset** | Explore freely, expect modern UX, want to push boundaries |
| **UI Preference** | Discord, TikTok feed, social layouts, Apple Liquid Glass |
| **Key Insight** | *"Products are built for the guys to buy, not for the guys to use"* |
| **Messaging Posture** | "Finally, a dealer tool that feels like your apps" |
| **Lead With** | Speed, modern interface, customization, experimentation |
| **Avoid** | Legacy framing, corporate feel, over-explaining basics |

### Bridging Message

> **"One platform. Your way. See everything in the interface that works for you."**

## Four Narrative Pillars

### 1. One House
*"All your conversations, calls, leads, and tasks in one place."*

Anchored in Charlie Lovell's reaction: "That's what we need. Just to make sure it's all in one house." CXM doesn't replace your CRM — it connects everything so nothing falls between systems.

### 2. Your Interface
*"~20 layouts built for how your team actually works."*

At NADA, every product looked like an email inbox — designed for buyers, not users. CXM asks a different question: what if a GM sees Outlook while a 23-year-old BDC rep sees Discord? Same data. Their preference.

### 3. Free for Clients
*"The platform that earns its place by making everything else work better."*

CXM isn't a product you buy — it's included with any CarBot service. No new budget line. No new vendor approval. The more you use CarBot, the more CXM does for you.

### 4. AI That Watches
*"Appointments schedule themselves. Tasks complete themselves. You just sell."*

After every call, AI reviews what happened. Appointment set? Scheduled. Callback requested? Task created. Trade mentioned? Flagged. Every night, it reviews every open opportunity. AI that doesn't just talk — it follows through.

## Key Risks and Mitigations

| Risk | Mitigation |
|------|-----------|
| Open-source timeline not yet public | Mark `[TIER C: INTERNAL ONLY]` until announced |
| "Free" could undervalue the platform | Frame as "included with CarBot services" not "free CRM" |
| First dealer deployment is very recent | Lean on 6-month internal usage + 18-month Coach data as proxy credibility |
| UI theme gallery could feel gimmicky | Frame through the generational insight, not cosmetic customization |
| VIN Solutions text-as-note limitation | Document honestly as CRM-side constraint, not CarBot limitation |
| No production ROI data yet | Don't promise numbers; use process/capability language instead |
