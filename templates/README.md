# GTM Output Templates

This directory contains templates for the outputs generated by each GTM pipeline stage.

## Templates

| Template | Stage | Agent | Purpose |
|----------|-------|-------|---------|
| `product-intelligence.md` | GTM-001 | /product-intel | Product Intelligence Document |
| `positioning-brief.md` | GTM-002 | /market-positioning | Positioning Brief + Claims Ladder |

## Usage

These templates provide structure for agent outputs. Agents should:

1. Copy the relevant template
2. Fill in all sections
3. Add evidence tags to all claims
4. Complete the Handoff Notes section
5. Store output in Notion GTM Outputs database

## Template Structure

Each template includes:

- **Header**: Metadata (agent, date, version)
- **Sections**: Stage-specific content areas
- **Tables**: Structured data (glossary, claims, etc.)
- **Handoff Notes**: Required completion summary

## Evidence Tags

All templates use this evidence tag format:

```
[EVIDENCE: repo <path>]
[EVIDENCE: repo <path>#Lx-Ly]
[EVIDENCE: notion <page-title>]
[EVIDENCE: transcript <date> <timestamp>]
[EVIDENCE: provided-by-user]
[EVIDENCE: unknown]
```

Unverified claims must be marked: `[UNVERIFIED]`

## Handoff Notes

Every output must end with Handoff Notes:

```markdown
## Handoff Notes

**Confidence level**: High / Medium / Low by section (and why)
**Evidence coverage**: X% of claims backed by evidence tags
**Gaps identified**: [Specific info needed]
**Risks to watch**: [Legal, competitive, operational]
**Recommendations for next agent**: [Do's and don'ts]
**Questions for human review**: [Decisions needing judgment]
```

## Website, Sales, and Demo Templates

Stages 3a, 3b, and 3c outputs are more complex and less templated:

- **Website Copy** (3a): Multi-page package with audience variants
- **Sales Enablement** (3b): Multiple deliverables (one-pager, battle card, etc.)
- **Demo Package** (3c): Paths, scripts, environment specs

See the agent prompts for detailed output specifications:
- `carbot/prompts/agents/website-copy.md`
- `carbot/prompts/agents/sales-enablement.md`
- `carbot/prompts/agents/demo-architect.md`
