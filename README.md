# CarBot Cloud CXM — Go-To-Market Pipeline

> Free, AI-native dealer experience platform. One platform. Your way.

## What Is CXM?

CarBot Cloud CXM (Customer Experience Manager) is a free platform for dealers engaged with CarBot services. It serves as the central hub for all CarBot offerings — unifying communications, AI voice agents, workflows, and CRM/DMS integrations in one interface that adapts to each user.

## Dual-Audience Strategy

This GTM addresses two distinct user populations:

| Audience | Profile | UI Preference | Messaging Posture |
|----------|---------|---------------|-------------------|
| **Traditional Buyers** | GMs, Operating Partners, seasoned staff | Outlook, Gmail, Apple Mail | "Everything you know, now in one place" |
| **Tech-Savvy Users** | BDC agents, newer salespeople, digital-native managers | Discord, TikTok, social feeds | "Finally, a dealer tool that feels like your apps" |
